# skills 目录说明

Skill 是“会组织工具完成子任务的能力”。在融合图谱中，它对应 `skill_process` 节点，不是单个函数工具，而是一个可复用、可组合、可编排的工作流单元。

当前三个 Skill：

1. `operation_check`
   - 场景：电网操作校核智能体。
   - 目标：判断操作方案是否合规、是否存在机理风险、需要补充哪些步骤。
   - 调用工具：图谱查询、拓扑分析、模拟潮流校核、调规检索、LLM。

2. `fault_plan_generation`
   - 场景：电网故障处置预案生成智能体。
   - 目标：根据故障场景召回预案，分析影响范围，生成处置步骤和依据。
   - 调用工具：预案召回、图谱查询、拓扑分析、模拟稳定评估、调规检索、LLM。

3. `power_flow_calculation`
   - 场景：电网潮流计算场景智能体。
   - 目标：组织断面潮流计算、运行方式调整后潮流越限校核、潮流快速估计和结果解释。
   - 调用工具：数据源查询、图谱查询、潮流快速估计模型、潮流计算算子、潮流与越限校核工具、LLM。

每个 skill 目录包含：

- `skill.py`：工作流实现。
- `prompt.md`：LLM 报告生成提示词。
- `demos.json`：该 skill 覆盖的 demo 名称。

当前 demo 的核心思路是：课题5智能体面对业务问题时，先匹配一个技能与流程节点，再由该流程组织工具调用节点，并由调规、预案、设备、运行规则、专家经验等知识实体节点提供约束和解释依据。
